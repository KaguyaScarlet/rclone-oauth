Overview

This application is a personal backup tool that uses rclone to access Google Drive.

Data Access

The application accesses Google Drive data solely for the purpose of creating and maintaining personal backups.

Data Sharing

This application does not sell, rent, or share Google Drive data with third parties.

Data Storage

Backup data is stored in the user's Google Drive account. The application does not operate a separate server for storing Google Drive content.

For questions regarding this application, please contact the application owner through the contact information associated with this Google Cloud project.
